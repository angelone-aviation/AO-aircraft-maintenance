# Inventory attachments

Open **Inventory → Details** for a saved stock item and find **Attachments** below the item fields. Choose an image or PDF, then select **Upload attachment**. Add more files by repeating the upload.

PDF, JPEG, PNG and WebP files are supported, up to 7 MiB per file. Images have previews; each attachment has an Open and Download control. Files remain attached when stock quantities or item details change. In **New stock item**, select one or more files under **Attachments** before choosing **Save**. The item is saved first, then the selected files upload. If an upload fails, the saved item opens with the remaining files ready to retry; successful uploads are retained.

Uploads require an online connection and Flight Program administrator access (the app's messages say "inventory administrator") in the active Flight Program. Connected deployments store files in Convex storage and list them on the stock item; each opens through a five-minute link asked for while it is on screen ([file links](file-links.md)), so offline it reads "File unavailable. Reconnect and reopen the item." Demo attachments persist in the browser’s saved demo data. Existing inventory permissions control which attachments appear in a user’s workspace.
